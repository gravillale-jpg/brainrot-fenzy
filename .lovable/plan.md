## Текущее состояние

В архиве готовы этапы 1–4: схема БД (12 таблиц + RLS), вход по нику, кликер с анти-читом (25 кл/сек на сервере), инвентарь с экипировкой, перехватчик fetch для авторизации server-fn. Каталоги засеяны минимально (~7 brainrot'ов, ~7 петов, 4 квеста). Маршруты `/shop`, `/quests`, `/leaderboard`, `/stats` — заглушки на 1 строку.

В рабочем `/dev-server` сейчас лежит пустой шаблон TanStack Start без backend. Сначала импортирую загруженный архив, затем достраиваю недостающее по промпту.

## План

### Шаг 1 — Импорт и Cloud
- Скопировать содержимое zip в `/dev-server` (src/, supabase/, package.json, vite.config и т.д.).
- Включить Lovable Cloud, применить существующие миграции, поставить зависимости (`framer-motion`, `zustand`, `i18next`, `react-i18next`, `@supabase/supabase-js`, `lucide-react` и пр., если их нет).
- Проверить, что превью отдаёт 200 и вход по нику работает.

### Шаг 2 — Расширение каталогов (этап 6 «Питомцы» + Brainrots)
Миграция-сид:
- **20 Brainrot'ов** по всем редкостям (common→secret), включая Tung Tung Sahur, Skibidi Toilet, Rizzler, Sigma, Gyatt, Fanum Tax, Ohio, Mewing, Looksmaxxing, Ballerina Cappuccina, Tralalero Tralala, Bombardiro Crocodilo и др. Поля: base_click_mult, base_passive, sell_price.
- **50 уникальных Pets** в стиле brainrot, по редкостям, с бонусами (click_mult, passive_mult, roll_luck, quest_bonus) и принадлежностью к тематическим сетам (Sigma Squad, Skibidi Crew, Mewing Trio, Gyatt Empire, Italian Brainrot, Ohio Gang).
- **~200 шаблонов квестов** в `quests_catalog` (клики, покупки, роллы, продажа, экипировка, накопление BToken и т.п.) с наградой только в BToken.
- AI-картинки (через `imagegen`) для топ-используемых brainrot'ов и нескольких петов; остальные — эмодзи/SVG-плейсхолдеры в стиле, чтобы не раздувать стоимость.

### Шаг 3 — Магазин (этап 5)
- Таблица `user_shop` уже есть. Server-fn `getShop`, `rerollShopIfExpired`, `buyShopItem`:
  - Личный 5-минутный таймер на игрока.
  - Common всегда в наличии; rare+ выпадают по таблице шансов; Secret — отдельный редкий ролл, в Brainrots-вкладке только brainrot'ы, в Pets-вкладке только петы.
  - Все цены/проверки/списания на сервере.
- UI `/shop`: две вкладки Brainrots/Pets, карточки с редкостью/ценой, обратный отсчёт, анимации Framer Motion, тосты.

### Шаг 4 — Система Roll (этап 7)
- Таблица `user_brainrots` уже хранит экземпляры; добавить миграцией поле `modifiers jsonb` и `rolls_used int default 0`, если ещё нет.
- Server-fn `rollEquippedBrainrot`: 1–3 модификатора (click_mult / passive_mult), уровни Weak→Mythic с множителями ×1.05…×8.0, первые 3 ролла бесплатно, дальше экспоненциальная цена от редкости brainrot'а. Запись в `roll_history`.
- UI: гача-анимация прокрутки (Framer Motion + звук), история роллов, отображение модификаторов на экипированном brainrot'е, учёт модификаторов в `processClicks` и пассивном доходе.

### Шаг 5 — Питомцы: бонусы и синергия (этап 6 завершение)
- Расширить `equip/unequip` для до 3 петов, агрегировать бонусы в `user_state` (click_mult, passive_mult, roll_luck, quest_bonus).
- Синергия: 2–3 пета одной редкости и тематические сеты — доп. множитель и визуальный эффект на кликере.
- На кликере петы реагируют на клики (прыжки/вращение через Framer Motion).

### Шаг 6 — Квесты, статистика, лидерборд (этап 8)
- Server-fn `getDailyQuests` / `claimQuest`: ежедневный реролл 10 квестов в 00:00 МСК (Europe/Moscow), хранение в `user_quests`. Прогресс инкрементится в `processClicks`, `buyShopItem`, `rollEquippedBrainrot`, `equip/sell`.
- `/quests` — список с прогресс-барами и кнопкой Claim.
- `/stats` — агрегаты по `user_state` + история (общий заработок, клики, покупки, роллы, лучший пет/brainrot).
- `/leaderboard` — функция `get_leaderboard` уже есть; UI с топ-100 по BToken, обновление каждые ~10 сек через TanStack Query polling (Realtime опционально, оставлю как стрейч).

### Шаг 7 — i18n, темы, звук, полировка
- `i18next` с RU/EN, переключатель в `app-shell`.
- Тёмная/светлая темы через CSS-переменные в `styles.css`, переключатель.
- Базовые звуки клика/покупки/ролла + фоновая музыка с тумблером (Web Audio API, без сторонних библиотек).
- Дизайн: glow/частицы/градиенты по редкости, плавные анимации, форматтер чисел (K/M/B/T/Qa/Sx) уже есть в `lib/format.ts`.

### Шаг 8 — Финал
- Прогон сборки, фикс ошибок, проверка флоу: вход → клик → магазин → инвентарь → ролл → квест → лидерборд.
- Объяснение, как опубликовать сайт и что Lovable Cloud уже играет роль сервера (никаких внешних серверов подключать не нужно).

## Подтверждения
Промпт требует подтверждений после каждого крупного этапа. Предлагаю работать так: после **Шага 1** (импорт + Cloud) показываю состояние и жду «ок»; затем Шаги 2–3 одним подходом (магазин + расширенные каталоги) → подтверждение; затем Шаг 4 (Roll) → подтверждение; затем Шаги 5–6 (петы/синергия + квесты/статы/лидерборд) → подтверждение; затем Шаг 7 (i18n/темы/звук/полировка) → финал.

## Технические детали
- Все экономические расчёты — в `*.server.ts`, server-fn только с `requireSupabaseAuth`.
- Никаких Supabase Edge Functions: используем `createServerFn` (TanStack).
- RLS на всех пользовательских таблицах; каталоги — public read.
- Картинки brainrot'ов — `imagegen` (premium только для героев), петы — комбинация генерации и эмодзи-плейсхолдеров.
- Защита от спама: rate-limit на server-fn (клики уже ограничены), для покупок/роллов — серверная валидация баланса и таймеров.
